# Garage Électromécanique — Djelibougou, Bamako

Site web vitrine officiel du **Garage Électromécanique** situé à Djelibougou (Bamako, Mali), sous la direction de **M. Oumar Karamoko DIARRA**.

## 🚗 À propos

Atelier spécialisé en diagnostic électronique automobile, électricité auto, climatisation, mécanique générale et révision préventive toutes marques à Bamako.

- **Localisation** : Djelibougou, Bamako — Mali (Coordonnées GPS : `12.676418, -7.941333`)
- **Horaires** : Lundi au Samedi, 08h00 – 18h00 (Fermé dimanche)
- **Contact & WhatsApp** : +223 66 79 07 20
- **Responsable** : M. Oumar Karamoko DIARRA

## 🛠️ Stack technique

- **Framework** : [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling** : [Tailwind CSS v4](https://tailwindcss.com/)
- **Langage** : TypeScript
- **Optimisations** : Responsive mobile/desktop, SEO sémantique, Schema.org LocalBusiness JSON-LD, Open Graph, Geo tags, PWA theme tags.

## 🚀 Lancement local

```bash
# Installation des dépendances
npm install

# Démarrage du serveur de développement
npm run dev

# Build de production
npm run build
```
